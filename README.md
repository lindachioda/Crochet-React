# 🧶 Crochet App

A guided React project featuring a crochet product catalog fetched from mine custom JSON Server API. Products are displayed in a list and organized by category, allowing users to browse and filter the available items.
This is a guided learning exercise focused on practicing React, TypeScript, API integration with Axios, data fetching, and dynamic filtering.
